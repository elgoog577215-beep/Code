## Why

教师分析主线已经具备班级、作业、题目和学生证据下钻，但当前界面仍存在关键状态缺失、移动端入口不可达、无效数字重复、学生证据切换往返和深链接失效等问题。此次改造以真实教学任务为准，减少查找、滚动和来回切换，不增加装饰性统计或解释文案。

## What Changes

- 在班级入口直接展示名册人数、已提交人数和未提交人数，帮助教师判断先看哪个班级。
- 压缩移动端教师头部，并将教学分析与四个管理入口完整呈现，避免横向截断。
- 在窄屏将对象路径收敛为“上一级 / 当前对象”，保持返回能力并减少首屏占用。
- 将作业题目行的“有效修改中位数”替换为未提交人数，并把移动端行内指标合并到同一状态带。
- 将题目学生列表按已提交与未提交分组，未提交者不再重复展示无意义的零提交、零修改。
- 将教师学生成长页改为紧凑的所选提交对比，删除与页头重复的统计和无数据空卡；学生端成长仪表盘保持不变。
- 在成长、提交证据和 AI 分析之间保留同一套提交选择器，补齐标签页语义和当前提交上下文。
- 补齐教师学生详情的服务端前端路由转发，使页面可刷新、可收藏、可直接打开。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `teacher-console-ui`: 强化教师分析入口的信息密度、窄屏可达性、学生证据跨标签切换、无效信息裁剪和深链接连续性要求。

## Impact

- 前端：教师工作台头部与侧栏响应式样式、教师分析页面组件、学生题目证据工作区、教师模式成长展示及中英文文案。
- 后端：`FrontendForwardController` 增加教师学生详情正式路由转发，并补充对应测试。
- 数据与 API：复用现有班级学情、作业总览、提交证据与成长接口，不新增数据库字段或统计口径。
- 兼容性：不改变学生端页面结构，不改变现有 API 响应结构。
